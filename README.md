# Schedule Planner

Schedule Planner — это веб-приложение для управления личным расписанием. Проект создан на чистом JavaScript без сторонних фреймворков и демонстрирует работу с DOM, событиями, пользовательским вводом, массивами объектов и модульной структурой кода.

## Цель проекта

Цель проекта — развить и подтвердить практические навыки программирования на JavaScript, включая работу с DOM, событиями, обработкой данных, валидацией форм и организацией кода в модули.

## Основные функции

- Добавление событий через форму.
- Валидация пользовательского ввода.
- Отображение списка событий из массива объектов.
- Редактирование события через модальное окно.
- Удаление события.
- Поиск события по названию.
- Фильтрация событий по категории.
- Сортировка событий по дате или названию.
- Сохранение данных в `localStorage`.
- Адаптивный современный интерфейс.

## Используемые технологии

- HTML5
- CSS3
- JavaScript ES6+
- DOM API
- LocalStorage
- JavaScript Modules

## Установка и запуск

1. Склонируйте репозиторий:

```bash
git clone https://github.com/username/schedule-planner.git
```

2. Перейдите в папку проекта:

```bash
cd schedule-planner
```

3. Запустите проект одним из способов:

- откройте файл `index.html` в браузере;
- или используйте расширение Live Server в Visual Studio Code.

Дополнительные зависимости не требуются.

## Пример использования

1. Введите название события.
2. Выберите дату, время и категорию.
3. Нажмите кнопку **Добавить**.
4. Используйте поиск, фильтр и сортировку для удобной работы со списком.
5. Нажмите **Редактировать**, чтобы изменить событие, или **Удалить**, чтобы убрать его из списка.
